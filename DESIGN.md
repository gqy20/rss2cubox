# RSS2Cubox design

Approved direction: B, warm reading journal. Homepage combines B1's lead story with B3's compact reading list; topic pages use B2's technical/policy comparison.

- Canvas: #f6f3ef; surfaces: #fffefd; ink: #34312e; secondary: #706961.
- Primary: #9c5741; primary tint: #f5e6df; olive: #626d4b; olive tint: #edf0e6.
- Serif editorial headings: Noto Serif SC / Songti SC / SimSun; sans UI: system-ui / PingFang SC.
- Main panels 20px radius, controls 10px, search and segments pills. No nested decorative cards.
- Desktop sidebar 184px, compact top search, content padding 28–36px. Adapt panels to one column on smaller screens.
- Motion is short state feedback, not page entrance choreography.
- No stock cover images required. Content, sources, citations and statuses carry the hierarchy.
