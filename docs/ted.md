# 他山青年 TED 灵感共创队

前端为观众阅读界面，首页直接显示最新整理完成的报告。选题整理和报告生成由后台完成。

## 页面

| 路径 | 用途 |
| --- | --- |
| `/ted` | 最新报告，存在历史报告时在末尾显示归档 |
| `/ted/[id]` | 阅读指定一期 |
| `/ted/manage` | 兼容旧链接，跳转栏目首页 |
| `/ted/manage/[id]` | 兼容旧链接，跳转单期阅读页 |

不提供密钥登录、素材选择、文本编辑、保存或发布按钮。标题为空的初始素材草稿不出现在栏目中；已整理报告从 `draft` 读取并移除主持人备注。`published` 和历史版本作为后台记录保留。

## 标题与期号

栏目全称置于报告顶部，本期内容标题在下方。侧栏简称“他山青年 TED”。期号使用 `10.23 期`，优先使用 `edition_date`，其次为北京时间的 `live_at` 日期；旧数据缺失时按覆盖结束日期的次日兼容。内部序号仅用于记录排序。

## 阅读布局

宽屏正文与原文依据并排，使用完整面板宽度；窄屏上下排列。目录可定位议题，正文引用可定位对应来源。封面、配图、直播及回放按实际数据展示。

完整参考资料每条一行，以固定列宽的“来源 | 标题”呈现，长标题省略并保留完整悬停标题。点击资料标题打开 AI 分析抽屉，按该期引用的 URL 查询现有文章或政策分析；原文链接独立保留。优先使用实时分析，记录不可用时回退到已保存的分析快照，引用说明与逐篇 AI 分析分别展示。报告不展示额外的后续跟进章节。页脚将素材范围、数据截止与更新时间合为紧凑一段。章节用间距与字号区分，不使用装饰性横线。

## Agent 阅读

站点 `/llms.txt` 提供完整读取约定，仓库入口 `docs/llms.txt` 同步说明。无需认证：

- `GET /api/ted`：最新在前的报告摘要，最多200期，不使用游标。
- `GET /api/ted/[id]`：观众可见的正文和引用；不返回主持人备注、编辑状态、额外跟进章节或旧分析快照。
- `GET /api/ted/[id]/source?id=<source.id>`：引用对应的现有逐篇 AI 分析，正文接口的每条来源提供 `analysis_url`。没有分析时返回 `analysis: null`，引用说明单独保留。

## 后台生成

```sh
# 检查素材，不调用模型
uv run python -m rss2cubox.ted_report_agent --start 2026-10-16 --end 2026-10-22 --dry-run

# 生成报告，预算上限默认5美元
uv run python -m rss2cubox.ted_report_agent --start 2026-10-16 --end 2026-10-22 --max-budget-usd 5
```

前端服务需运行。命令读取根目录 `.env` 和 `web/.env.local`，复用现有 Agent SDK、提示词注册中心与网页核实工具；提示词在 `prompts/ted_report.yaml`。保存后通过阅读链接查看，无前端编辑步骤。

后台接口保留 `POST /api/ted` 创建素材快照、`GET /api/ted/materials` 读取候选、`PATCH /api/ted/[id]` 保存。写操作检查同源 Origin 和仅服务端使用的 `TED_WRITE_TOKEN` Bearer 凭据（至少32字符）；生成命令自动读取环境配置，观众不需要输入密钥或登录。响应不缓存。

存储复用现有 PostgreSQL 连接池，首次创建时幂等建表，保存使用版本比较处理并发。`publicReport` 过滤主持人备注，阅读页和历史预览使用同一内容格式。

## 数据口径

覆盖日期为北京时间自然日，优先按原始发布时间选材，缺失时用首次收录时间并注明。截止时间与统计固定在快照中，候选数量不冒充全区间收录数量。

技术候选需要已有分析，按专题/来源平衡选取，最多180条；政策需要已分析且相关度至少2，最多60条。同URL移除常见追踪参数后去重，转载是否独立仍需核实。生成引用只能从提供的素材映射。
